# FraudGuard AI

**Status:** specification only — implementation not started.

FraudGuard AI is a learning-oriented fraud risk scoring and human-led investigation platform using synthetic data. The target system is documented in `FraudGuard_AI_Cahier_des_Charges.pdf` and `FraudGuard_AI_README.md` (supplied separately).

## Current scope

- Sprint 1 / Story S10: product scope, personas, journeys, and preliminary quality criteria.
- No runtime services, tests or models have been implemented or executed.

Sprints 1–6: end-to-end MVP. Sprint 7: MLOps/LLMOps and monitoring. Sprint 8: documentation and optional deployment extensions.

## Conventions

Documentation: French. Code, identifiers, API and commit messages: English. Only synthetic or duly authorized public data. The system never autonomously blocks accounts or adjudicates fraud.
